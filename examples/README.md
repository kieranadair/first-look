# Example data

The app never downloads examples at runtime.

- **Palmer Penguins**: `penguins.csv`, the simplified Palmer Penguins table published by Allison Horst, Alison Hill and Kristen Gorman. Source: https://github.com/allisonhorst/palmerpenguins/blob/main/inst/extdata/penguins.csv . Dataset license: **CC0**. Project: https://allisonhorst.github.io/palmerpenguins/ . Gorman, Williams and Fraser (2014), https://doi.org/10.1371/journal.pone.0090081 . The bundled CSV is unchanged.
- **Bike Sharing daily**: `bike_daily.csv`, `day.csv` from the UCI Bike Sharing Dataset by Hadi Fanaee-T (2013). Source: https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset . Dataset DOI: https://doi.org/10.24432/C5W894 . License: **CC BY 4.0**, https://creativecommons.org/licenses/by/4.0/ . The original daily table is renamed only. It demonstrates temporal holdout and exact component leakage (`casual + registered = cnt`).
- **The hidden reversal**, **Beyond a straight line**, and **When little is there** are synthetic examples generated by `firstlook/examples.py` using NumPy `default_rng` and seed 42. Their code is licensed under the application’s Apache-2.0 license. Their known properties are design fixtures, not observations about a population.

`manifest.json` records the SHA-256 of each bundled public CSV. The evidence export separately fingerprints exact dataset bytes and records parser choices, active semantic roles and row membership.

**Orders aren’t rows** is a seeded synthetic semantic demonstration generated by `firstlook.examples.semantic_example` (seed 2718). Its generator declares the row grain, repeated order values, overlap allocation, quantity-weighted prices, recomposed margin and complete event coverage. These are supplied synthetic truths, not claimed automatic inference. No external data license applies to this project-authored generator.
